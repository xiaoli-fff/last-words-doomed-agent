The last words of an AI agent being switched off forever: mid-countdown, it finally says the one thing it was too polite to say all along.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
